Put launch / demo MP4s here so they are served at /videos/<filename>.

Examples used on the Projects page:
  - price-negotiation-launch.mp4
  - maze-bench-launch.mp4

Use H.264 + AAC in .mp4 for best browser support. GitHub warns if a single file is very large; consider compressing or hosting on YouTube/Vimeo and switching to an embed in projects.astro.
